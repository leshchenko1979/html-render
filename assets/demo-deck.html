Why a fixture

Two recipes need a document in the repo

Determinism

Render the same file ten times and compare the checksums. A fixture small enough to commit makes that reproducible from a fresh clone.

Cost

Peak RSS and wall time on a known input, so a regression shows up as a number rather than as an opinion.

Clip mode

Four section.slide elements, so --clip has exactly four matches and the count is checkable.
